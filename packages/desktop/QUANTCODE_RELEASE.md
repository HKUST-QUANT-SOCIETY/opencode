# QuantCode desktop release

The `QuantCode desktop installers` workflow builds the desktop application from this repository for:

- macOS Intel: DMG and ZIP
- macOS Apple Silicon: DMG and ZIP
- Windows x64: NSIS installer
- Linux x64: AppImage, DEB, and RPM

Run the workflow manually to produce downloadable GitHub Actions artifacts. Set `publish` to `true`, or push a tag named `quantcode-vX.Y.Z`, to publish the same verified files to a GitHub Release. Published builds use the `latest*.yml` metadata generated by electron-builder for in-app updates.

The desktop source lives in the `HKUST-QUANT-SOCIETY/opencode` fork, while public QuantCode releases live in `HKUST-QUANT-SOCIETY/quantcode`. Add a fine-grained `QUANTCODE_RELEASE_TOKEN` secret to the fork with `Contents: write` access to the QuantCode repository. Artifact-only runs do not need this token.

## Release signing

Unsigned installers are still produced when signing secrets are absent, which keeps development builds testable. A public release should configure these repository secrets before enabling `publish`:

### macOS

- `APPLE_CERTIFICATE`: base64-encoded Developer ID Application `.p12`
- `APPLE_CERTIFICATE_PASSWORD`
- `APPLE_API_KEY_CONTENT`: contents of the App Store Connect `.p8` key
- `APPLE_API_KEY_ID`
- `APPLE_API_ISSUER`

The release workflow imports the certificate, signs the application with hardened runtime enabled, notarizes it, and verifies the resulting signature.

### Windows

- `AZURE_CLIENT_ID`
- `AZURE_TENANT_ID`
- `AZURE_SUBSCRIPTION_ID`
- `AZURE_TRUSTED_SIGNING_ACCOUNT_NAME`
- `AZURE_TRUSTED_SIGNING_CERTIFICATE_PROFILE`
- `AZURE_TRUSTED_SIGNING_ENDPOINT`

When these values are present, the workflow authenticates to Azure Trusted Signing, signs the NSIS executable, and verifies its Authenticode status.

Linux packages do not require platform code signing. Distribution repositories may add their own package signatures later.

## Local macOS package

From `packages/desktop`:

```bash
OPENCODE_CHANNEL=quantcode bun run build
OPENCODE_CHANNEL=quantcode CSC_IDENTITY_AUTO_DISCOVERY=false bunx electron-builder --mac --publish never --config electron-builder.config.ts
```

Local unsigned builds skip notarization. Release builds enable it automatically when all Apple API key variables are present.
